# Pokerito! Um jogo simplificado de Poker.

## As regras são estas:

Há dois jogadores: você e o computador.
O dealer dará uma carta para cada jogador.
Em seguida, o dealer irá revelar cinco cartas).
O jogador com mais cartas que coincidam com as cartas que o dealer revelou, vence!
Se o número de coincidências for igual, todos vencem!
